# 交付前补充检查

桌面和手机截图、验收失败如实说明、汇报格式，按 design-workflow 执行；长视频的连续性和对白检查由长视频制作流程负责。下面是它们之外的检查项。

## 网页与界面

- [ ] 有异步数据的页面等几秒再截图，否则看到的是一排 0。
- [ ] canvas、粒子类动效截图太早会稀疏，先让它跑到稳态（同步推进 200 帧以上）再截。
- [ ] 非首屏状态（轮播第 N 屏、弹层、展开态）用脚本切过去再截。
- [ ] 浅色和深色各看一次。
- [ ] 动效真的在跑：`el.getAnimations().length` 大于 0；`display:none` 切换的元素用了 allow-discrete 和 `@starting-style`。
- [ ] 孤儿变量：把用到的 `var(--x)` 和定义过的变量对一遍，未定义的会让整条声明失效。
- [ ] 页面用到的类都有样式，JS 引用的 id 都存在，`href="#x"` 都有对应锚点。
- [ ] 按钮和面板边界可见，分割线是半透色。
- [ ] 默认克制配色下没有纯黑大面积底、没有失控霓虹、阴影透明度不超过 0.08；选了需要这些元素的风格时，按 `anti-kitsch.md` 的用法核对。
- [ ] 性能：blur 层数、粒子数量、常驻动画有上限，移动端降级生效，滚动不掉帧。
- [ ] 对外禁词扫描（内部代号、模型名、服务器位置等），注释和 alt 文本也查。
- [ ] 修改既有页面时，逐条列出文案的原文、新文和理由，证明只改了事实。

## 图片与海报

- [ ] 文件真实落盘：看尺寸和字节数，只报成功不算。
- [ ] 画幅和投放平台一致（横版、竖版、方图）。
- [ ] 主体清晰可指认，商业图里产品在场。
- [ ] 人像没有蜡像感和 CG 皮肤。
- [ ] 主风格不超过两个，争议元素按风格依据使用。
- [ ] 画面上的数字都能在原始资料里逐字找到。

## 视频与音频

- [ ] 驱动音频（口型、卡点）是否真的生效用互相关验证：抽出音轨重采样到 16kHz，与源音频做归一化互相关，大于 0.6 才算对上，别只靠听感。
- [ ] 下载下来的文件检查大小和类型：几百字节的文本多半是错误页。
- [ ] 结尾留了一拍安静再出标识，主色没有中途变调。

## 文案

- [ ] 破折号为 0：`grep -c "$(printf '\342\200\224')" 文件`。
- [ ] 没有先否定再肯定的对举句：`grep -nE "不[是].*(，|,)是|不[是].*而是" 文件`。
- [ ] 没有三连排比、感叹号、自造口号。

## 汇报

只写完成内容、文件位置、验证证据和没验到的地方。没截到图就写没截到。
