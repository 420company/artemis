# 生图提示词补充

分层模板、相机词、微观细节、负面词、风格融合比例，设计工作流和 dirty-prompt 已经提供，这里不重复。
长视频里的角色锁定、三视图、参考图身份提取、真人质感，由引擎的长视频制作流程和画面一致性处理负责。
这里只收它们没覆盖的几条。

## 单张人像的真实质感

- 少用 8K、masterpiece、best quality、ultra detailed 这类画质套话，它们容易把人像推向蜡像和 CG 皮肤。
- 用摄影语言描述皮肤：natural skin texture、visible pores、imperfect human skin、editorial photography、35mm film grain。
- 叠加的风格约束和美化词越多，皮肤越容易失真。质感变差时先减少约束，再考虑加负面词。
- 会把画面拉向动漫的词（如「二次元」「Q 版」）要删掉或换成摄影词，除非本来就要动漫风。
- 只使用本人授权或委托人有权使用的照片。部分模型不接受真人照片作参考，这是模型策略，按策略换方案（例如改用原创角色），不要设法绕过。

## 卡通角色合成进实景

- 走图生图，把角色参考图传进去；纯文生图只会得到通用形象。
- 提示词写明四件事：要保留的角色特征、真实场景、机位、角色与场景的质感关系（保持卡通质感叠在写实场景上，或统一成一种质感）。

## 数字、图表、价格画面

- 图像和视频模型渲染数字容易糊和错。数字、K 线、表格用代码绘制（如 Python 图像库、程序化视频框架），再与生成画面合成。
- 画面上的每个数字都要能在原始资料里逐字找到。
