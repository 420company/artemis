# 生图提示词补充

分层模板、相机词、微观细节、负面词、风格融合比例，设计工作流和 dirty-prompt 已经提供，这里不重复。
长视频里的角色锁定、三视图、参考图身份提取、真人质感锁，由引擎的长视频制作流程和画面一致性处理负责。
这里只收它们没覆盖的几条。

## 单张人像的真人质感

- 少用 8K、masterpiece、best quality、ultra detailed 这类画质套话，它们会把人像推向蜡像和 CG 皮肤。
- 用摄影语言描述皮肤：natural skin texture、visible pores、imperfect human skin、editorial photography、35mm film grain。
- 「越改越像蜡像」时先减层：风格锁、美化词、关键帧锚定层层叠加会扼杀有机感，删词比加「no waxy skin」有效。
- 文案里会把画面拉向动漫的词（「二次元」「Q 版」「萌」）要删掉或换成摄影词，除非本来就要动漫风。
- 只使用本人授权或委托人有权使用的照片。部分模型不接受真人照片作参考，这是模型策略，按策略换方案（例如改用原创角色），不要设法绕过。

## 卡通形象进真实场景

- 必须走图生图，把真实的角色参考图传进去；纯文生图只会得到通用形象。
- 可靠结构：保留参考角色的全部特征（皮肤、耳朵、眼睛、发型、服装）+ 放进真实房间或街景 + 明确机位（如正面自拍、桌面摄像头视角）+ 角色保持卡通质感叠在写实场景上 + 适度的视频通话画质 + 无文字。
- 形象对目标人群友好：表情放松、姿态自然，避免猎奇和冒犯。

## 数字、图表、价格画面

- 图像和视频模型渲染数字容易糊和错。数字、K 线、表格用代码绘制（如 Python 图像库、程序化视频框架），再与生成画面合成。
- 画面上的每个数字都要能在原始资料里逐字找到。
