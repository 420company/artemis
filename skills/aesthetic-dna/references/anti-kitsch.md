# 廉价感排查

判断画面和页面是否显得廉价的总原则，以及黑金、霓虹、故障效果这类争议元素怎么处理。
每种风格自带的避免项在设计工作流的 30 风格库里，这里只管跨风格的判断。

## 一、取舍原则

1. 大众审美里有效的部分要保留：观众一眼看得懂、记得住的具象画面，往往正是作品被接受的原因。
2. 产品和主题要清楚在场。为了显得克制把主体藏起来，作品就失去了它的功能。
3. 问题通常出在执行粗糙，元素本身可以中性看待。
4. 判断标准：情绪和画面是否一致，主体是否清楚，细节是否经得起停帧细看。

## 二、任何风格都要避免

| 现象 | 处理 |
|---|---|
| 商业片里只有空镜，产品缺席 | 产品实体在场、清晰可指认、被光和主色包裹 |
| 人物低俗化、把性感拍成暴露和油腻 | 用姿态、光线和眼神表达魅力 |
| 制造紧迫感的营销话术、机械腔文案 | 见 `web-ui.md` 第八节 |
| 一屏塞满、焦点打架 | 一屏一个主焦点 |

编造指标按 design-workflow 的禁止虚构处理；假笑、统一摆拍这类问题见长视频风格库各类型的避免项。

## 三、争议元素：按所选风格决定

先确认所选风格（见设计工作流的风格库）是否需要这个元素。需要就用，并按「稳妥用法」执行；不需要就别加。

| 元素 | 粗糙做法 | 适合的风格或题材 | 稳妥用法 |
|---|---|---|---|
| 黑金 | 大面积亮金、金色渐变大字、黑底低对比金字 | 装饰艺术、新古典、奢侈品珠宝、酒店、颁奖 | 金只做细线、细边和小面积点缀，配象牙白或深青；用哑光拉丝质感；金字对比度要够 |
| 霓虹 | 满屏荧光、没有主色纪律、频闪 | 赛博朋克、蒸汽波、酸性、夜生活题材 | 霓虹当场景里的真实光源（招牌、湿地面反射），背景压暗；主色数量见长视频风格库的色调纪律 |
| 故障 / RGB 分离 | 全屏噪点、拿 glitch 当万能转场 | 故障艺术、超流行和故障核音乐、电子乐、安全题材 | 局部、几帧、主体始终可辨，卡在节奏点；闪烁每秒不超过 3 次 |
| 蓝紫科技感 | 默认「科技就是蓝紫」、发光线框 | 赛博朋克题材、复古 CRT、克制版新未来主义 | 有叙事理由才用；冷光里留一个暖点 |
| 漂浮粒子 | 光点当装饰、粒子爆炸出标识 | 品牌动效里「从单点生长」、数据可视化 | 粒子要有物理（受力、聚散有因），数量设上限，移动端降级 |
| 字符雨、合成波太阳、扫描线 | 拿符号冒充风格 | 蒸汽波、复古年代、CRT 题材 | 当年代证据少量出现，配真实的时代材质 |
| 满屏代码、终端画面 | 冒充「AI」「科技」 | 产品本身是开发者工具 | 展示真实、可读的界面和输出 |
| 产品旋转、360 度转台 | 转台占满全片、代替一切镜头语言 | 电商功能演示、开箱、科技新品发布（长视频风格库里这几类本来就用转台和环绕），以及用户可操控的 3D 配置器 | 前提是背景干净、转速慢而匀、穿插功能特写或拆解，转台只占其中一段；香水、珠宝、腕表这类情绪型品类避免，改用掠光、微距、局部揭示 |
| 纯黑大面积底 | 黑色块砸断柔和的页面叙事 | 新粗野、欧普、黑白海报 | 其余风格用带色偏的深色 |

高饱和撞色允许与否，由设计工作流按所选风格自动判断，这里不重复。

这样处理后，克制的默认值和需要鲜艳元素的风格不再冲突：默认按克制走，选了某个风格就按该风格的语言走，任何时候只处理粗糙的执行。

## 四、常见问题表现与排查方向

| 表现 | 先查 |
|---|---|
| 整体显得廉价 | 有没有真实图像；内容是否全挤在一页；对外是否露出冗长 ID 和开发者口吻 |
| 视觉太杂 | 焦点数量、装饰是否压过内容（风格数量规则见设计工作流） |
| 主次不清 | 一屏一个主焦点；说明文字是否压过行动按钮 |
| 文字拥挤 | 行宽、换行、段间距 |
| 操作不直观 | 控件是否堆在一处；状态是否一眼可辨 |
| 缺少电影感 | 光源单一、没有景深、色彩单一、没有动效 |
| 缺少质感 | 饱和度、阴影、边框可辨性、页面性能 |
| 单个控件难看 | 边界是否过弱、分割线是否过硬 |

## 五、交付物里写修改意见

评审时的直觉判断词不写进交付物。写给委托人的方案、注释、alt 文本、提交信息里，写成可执行的修改意见，例如「金色改为 1px 细边并降低面积」。
