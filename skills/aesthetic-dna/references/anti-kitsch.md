# 防土规则

判断「土不土」的总原则，以及黑金、霓虹、故障效果这类争议元素该怎么处理。
每种风格自带的「避免」清单在设计工作流的 30 风格库里，这里只管跨风格的判断。

## 一、味觉刻度：防土不等于灭绝

1. 土消灭不掉，有些土正是消费者买单的点。立场是引领，不迎合。
2. 留一味大众诱饵：为产品服务的具象诱惑，让人想要、看得懂、能复述。为了「高级」把产品藏没、只剩空镜，同样是失败。
3. 只杀廉价执行。元素本身无罪，廉价的是执行方式。
4. 做对的标志：内在情绪和具象画面焊在一起，缺一不可。

## 二、任何风格都砍掉的

| 现象 | 处理 |
|---|---|
| 编造的指标、跑分、参数堆砌 | 要么真实并写明来源，要么删 |
| 假笑、统一摆拍的笑容 | 换成真实反应，例如眼神恢复一点点光 |
| 商业片里只有空镜，产品缺席 | 产品实体在场、清晰可指认、被光和主色包裹 |
| 人物低俗化、把性感拍成暴露和油腻 | 用姿态、光线和眼神表达魅力 |
| 资金盘口吻、AI 腔文案 | 见 `web-ui.md` 第八节 |
| 一屏塞满、焦点打架 | 一屏一个主焦点 |

## 三、争议元素：按所选风格决定

先确认所选风格（见设计工作流的风格库）是否需要这个元素。需要就用，并按「不土的用法」执行；不需要就别加。

| 元素 | 廉价执行 | 适合的风格或题材 | 不土的用法 |
|---|---|---|---|
| 黑金 | 大面积土豪金、金色渐变大字、黑底低对比金字 | 装饰艺术、新古典、奢侈品珠宝、酒店、颁奖 | 金只做细线、细边和小面积点缀，配象牙白或深青；用哑光拉丝质感；金字对比度要够 |
| 霓虹 | 满屏荧光、没有主色纪律、频闪 | 赛博朋克、蒸汽波、酸性、夜生活题材 | 霓虹当场景里的真实光源（招牌、湿地面反射），主色不超过两个，背景压暗 |
| 故障 / RGB 分离 | 全屏噪点、拿 glitch 当万能转场 | 故障艺术、超流行和故障核音乐、电子乐、安全题材 | 局部、几帧、主体始终可辨，卡在节奏点；闪烁每秒不超过 3 次 |
| 赛博蓝紫科技感 | 默认「科技就是蓝紫」、发光线框 | 赛博朋克题材、复古 CRT、克制版新未来主义 | 有叙事理由才用；冷光里留一个暖点 |
| 漂浮粒子 | 光点当装饰、粒子爆炸出标识 | 品牌动效里「从单点生长」、数据可视化 | 粒子要有物理（受力、聚散有因），数量设上限，移动端降级 |
| 字符雨、合成波太阳、扫描线 | 拿符号冒充风格 | 蒸汽波、复古年代、CRT 题材 | 当年代证据少量出现，配真实的时代材质 |
| 满屏代码、终端画面 | 冒充「AI」「科技」 | 产品本身是开发者工具 | 展示真实、可读的界面和输出 |
| 产品旋转、360 度转台 | 用转台代替镜头语言 | 用户可操控的 3D 配置器（功能，不算镜头） | 镜头里用掠光、微距、局部揭示代替转台 |
| 纯黑大面积底 | 黑色块砸断柔和的页面叙事 | 新粗野、欧普、黑白海报 | 其余风格用带偏色的深色 |
| 高饱和撞色 | 所有区域都高饱和、没有主次 | 孟菲斯、童核、新波普、酸性、Y2K、极繁 | 每个颜色有角色，留白底或黑底缓冲 |

这样处理后，克制的默认值和需要鲜艳元素的风格不再冲突：默认按克制走，选了某个风格就按该风格的语言走，任何时候都只砍廉价执行。

## 四、常见负面评价对应的问题

| 听到 | 先查 |
|---|---|
| 很 low、山寨、廉价 | 有没有真实图像；是不是一页堆满；对外是否露出长 ID 和开发者口吻 |
| 太花 | 焦点数量、风格是否超过两个、装饰是否压过内容 |
| 太乱、主次颠倒 | 一屏一个主焦点；说明文字是否压过行动按钮 |
| 挤成一团 | 行宽、换行、段间距 |
| 不直观 | 控件是否堆在侧栏；状态是否一眼可辨 |
| 没有电影感 | 光源单一、没有景深、色彩单一、没有动效 |
| 不高级 | 饱和度、阴影、边框可见性、页面性能 |
| 很丑（指某个控件） | 边界是否被弱化、分割线是否是生硬白线 |

## 五、评审用语留在内部

「土」「廉价」是判断用语。写给委托人的方案、注释、alt 文本、提交信息里，改写成可执行的修改意见，例如「金色改为 1px 细边并降低面积」。
