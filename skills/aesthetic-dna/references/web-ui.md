# 网页与界面的审美规则

只收现有设计流程没写到的部分。目录、资产清单、配图数量、CSS 变量体系、语义化、不留假按钮、桌面和手机截图验收，按 design-workflow 执行；token 和组件文档交给 ui-design-system。
下面都是默认值和建议起点。项目已有设计语言、用户本轮要求、所选风格与之冲突时按后者走。

## 一、色彩与材质

- 深色界面默认不用纯黑 #000 做大面积底，改用带一点色偏的深色，色偏跟着品牌主色走，层级靠 3 到 5 级灰阶拉开。以黑白硬对比为语言的风格（新粗野、欧普、部分海报风）例外。
- 默认低饱和、哑光，可加一点微纹理（细颗粒、纸纹），整套配色留一个功能色点。
- 阴影透明度建议从 0.08 以内起步，阴影用来分层，不用来装饰。新粗野主义的硬边实色阴影是风格语言，可以用。
- 边框和分割线用低透明度的半透色（建议从 6% 到 12% 的不透明度起步），高对比的实色分割线会让界面显得生硬。
- 镜面高光、渐变边框默认不用；Y2K、酸性、新未来主义这类以材质反光为卖点的风格可用，限制在一两处主角元素上。
- 浅色为基准的产品：深色模式只重定义变量，同时接 `prefers-reduced-motion`、`prefers-reduced-transparency`、`prefers-contrast` 三个偏好。

## 二、排版

- 字距随字号变化：大字号适当收紧，正文保持默认，很小的字适当放开。一个 letter-spacing 用到底，总有某个字号不对。
- 正文行宽建议 65ch 左右；长句主动分行。
- 层级默认靠字号、字重和颜色深浅，不靠 `text-transform: uppercase`。英文小标签、构成主义和新粗野这类风格可以用全大写，同时加一点正字距。
- 营销页和应用界面是两套语言：营销页标题大、留白多、产品图主导；应用界面正文字号适中、列表紧凑、分组清楚。两套别混用。

## 三、结构与构图

- 负空间占比建议从 40% 左右起步（极繁、孟菲斯等高密度风格除外），版面可以从 12 列网格起步。
- 内容多的站点分页组织，用导航进入各功能页；子页不重复首页的大图。
- 每屏有自己的构图重点，避免整站套用同一种图文分栏。轮播或分屏切换时，切换层用不透明底色，避免残影。
- 对外界面避免露出冗长的 ID、完整路径和面向开发者的说明，必要时缩短或收进详情。

## 四、控件与层级

- 按钮要有清晰的可点击外观：边框、底色或两者之一。
- 面板、卡片之间要有可辨的边界。
- 一屏一个主焦点。说明文字、徽标、装饰的视觉权重低于行动按钮。
- 选中和状态切换优先用颜色、形状、底色变化表达，少用位移动画。
- 控件多时分组，或收进弹层、抽屉、独立页面。

## 五、动效

- 默认不做挡住内容的开场动画。滚动叙事、品牌首屏需要入场动效时（技法见 epic-design），内容在 1 秒内可读，并尊重减少动态偏好。
- 动画用 requestAnimationFrame 和 CSS transition/animation，不用 setTimeout 驱动帧。
- 滚动触发用 IntersectionObserver；页面不可见时（visibilitychange）暂停常驻动画。
- 适配 `prefers-reduced-motion`：减少或关闭位移和视差。
- 移动端降级：减少粒子数量，关闭光标光晕和卡片 3D 倾斜，`backdrop-filter` 准备不支持时的回退底色。
- 从 `display:none` 切到显示的元素，transition 默认不会启动：加 `transition-behavior: allow-discrete`，用 `@starting-style` 写起始态，再用 `el.getAnimations().length` 确认动画确实存在。
- 按压反馈建议 100 到 120ms 起步，超过 180ms 通常会觉得拖。
- 分段控件的滑块用等宽标签加 translateX，比动画 width 更顺。

## 六、毛玻璃

- 毛玻璃吃性能：blur 建议从 8 到 10px 起步，去掉常驻的 `will-change`，叠加的滤镜层能少则少。
- 祖先元素上的 `backdrop-filter` 会让 `position:fixed` 的子元素按祖先定位并被裁剪，下拉菜单和弹层要挂到 body 下。

## 七、工程细节里的审美

- 引用未定义的 CSS 变量会让整条声明失效。改变量名前全局搜一遍引用。
- 产品界面示意图可以用 CSS 或 SVG 绘制，清晰度高，也能跟随深浅主题。
- 图表、数字、价格这类必须准确的内容用代码绘制，不交给图像模型。
- 性能是体验的一部分：给粒子数、blur 层数、常驻动画数量设上限，canvas 动效在不可见时停帧。
- 异步数据加载前给骨架或加载状态，避免首屏出现无意义的空值。

## 八、文案（文案也是设计）

- 修改既有页面时，改动范围与需求一致：只更新失效的事实，已定稿的标题、正文、口号保持原样；改完列出原文、新文和理由。
- 需要新写文案时，先和委托人确认方向。
- 避免机械腔：破折号、先否定再肯定的对举句、三连排比、并列否定、表演式小标题、感叹号、书面连接词堆砌。
- 金融、会员、数字资产类产品，避免制造紧迫感和收益暗示的营销话术。
- 面向用户说话，避免开发者口吻；多语言站点不擅自切换语言。
- 每个项目维护一张对外禁词表：内部代号、供应商名、基础设施信息、尚未上线的功能等，注释和 alt 文本也要查。
