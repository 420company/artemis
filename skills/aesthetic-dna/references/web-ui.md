# 网页与界面的审美规则

只收现有设计流程没写到的部分。目录、资产清单、配图数量、CSS 变量体系、语义化、不留假按钮、桌面和手机截图验收，按 design-workflow 执行；token 和组件文档交给 ui-design-system。
下面都是默认值，项目已有设计语言、用户本轮要求、所选风格与之冲突时按后者走。

## 一、色彩与材质

- 深色界面默认不用纯黑 #000 做大面积底，用带一点蓝紫偏移的深色（如 #0a0a0f、#0d0d12），层级靠 3 到 5 级灰阶拉开。以黑白硬对比为语言的风格（新粗野、欧普、部分海报风）例外。
- 默认低饱和、哑光、加一点微纹理（细颗粒、纸纹），整套配色只留一个功能色点。
- 默认阴影透明度不超过 0.08，阴影用来分层，不用来装饰。新粗野主义的硬边实色阴影是风格语言，可以用。
- 边框和分割线用极低透明度的半透色（如 rgba(255,255,255,.06) 到 .12）。生硬的纯白横线最显廉价。
- 镜面高光、渐变边框默认不用；Y2K、酸性、新未来主义这类以材质反光为卖点的风格可用，限制在一两处主角元素上。
- 浅色为基准的产品：深色模式只重定义变量，同时接 `prefers-reduced-motion`、`prefers-reduced-transparency`、`prefers-contrast` 三个偏好。
- 「说不上来哪里不对」时先查有没有真实图像、层级是否清楚。直接换浅色主题通常只是掩盖问题。

## 二、排版

- 字距随字号变化，一个 letter-spacing 用到底总有某个字号是错的。参考：大标题 -0.035em，标题 -0.02em，正文 0，小字 +0.012em。
- 正文行宽 65ch 以内；长句主动分行，一行字太多就挤成一团。
- 不用 `text-transform: uppercase` 做层级区分，层级靠字号、字重和颜色深浅。
- 营销页和 App 页是两套语言，别混用：营销页用巨大标题（桌面 80 到 110px）、巨量留白、产品图主导、背景深浅交替；App 页用 15 到 17px 正文、紧凑列表、浅灰底分组。

## 三、结构与构图

- 负空间占比不低于 40%（极繁、孟菲斯等高密度风格除外），版面基于 12 列网格。
- 正式项目用多页结构：头图或标识在上，顶部导航进各功能页。所有内容塞进一页会显得像临时页。子页不机械重复头图。
- 每屏独立构图，避免整站都是左文右图分栏。全屏轮播式的产品展示里，每屏可以有自己的主题色和活体背景（缓慢流场、漂移画面墙、反向滚动画廊），切换时幻灯片底色要不透明，否则留残影。
- 对外可见的长 ID、长 URL、文件路径、开发者口吻的说明都显得廉价，缩短或收进详情。

## 四、控件与层级

- 按钮必须有边框或底色，纯文字当按钮看起来像坏了。
- 面板边界保持可见，弱化到看不见会让界面失去结构。
- 一屏一个主焦点。说明文字、徽标、装饰不能比行动按钮更抢眼。
- 选中和状态用静态标识（高亮点和灰点、底色变化），少用位移动画表达选中。
- 密集控件收进弹层、抽屉或新窗口，侧栏堆满按钮会让人看不到完整信息。
- 修排版就只修排版，不顺手改结构和配色。

## 五、动效

- 不做页面加载时的开场动画，内容直接呈现。
- 动画用 requestAnimationFrame 和 CSS transition/animation，不用 setTimeout 驱动帧。
- 滚动触发用 IntersectionObserver；页面不可见时（visibilitychange）暂停常驻动画。
- 适配 `prefers-reduced-motion`：减少或关闭位移和视差。
- 移动端降级：减少粒子数量，关闭光标光晕和卡片 3D 倾斜，`backdrop-filter` 准备不支持时的回退底色。
- 从 `display:none` 切到显示的元素，transition 默认不会启动：加 `transition-behavior: allow-discrete`，用 `@starting-style` 写起始态，再用 `el.getAnimations().length` 确认动画确实存在。
- 按压反馈 100 到 120ms，超过 180ms 会觉得拖。
- 分段控件的滑块用等宽标签加 translateX，比动画 width 更顺。
- 常驻的吉祥物或桌面宠物：原地微动作（呼吸、耳朵轻抖、尾巴摆动、视线移动）最耐看；走动、蹦跳、频繁眨眼很快让人烦。

## 六、毛玻璃与流体

- 毛玻璃好看但吃性能：blur 控制在 8 到 10px，去掉常驻的 `will-change`，叠加的滤镜层能删就删。
- 祖先元素上的 `backdrop-filter` 会让 `position:fixed` 的子元素按祖先定位并被裁剪，下拉菜单和弹层要挂到 body 下。
- 流体渐变背景（45 度、四色、400% 尺寸、十几秒一个循环）适合科技氛围和产品质感面，与酸性、Y2K、新未来主义搭配；克制系风格里只用在一个区块，并把饱和度降下来。
- 对话类界面：消息区保持干净，工具调用和日志折叠成紧凑卡片，激活态用浅底加左侧圆头竖条，比整块高亮更清楚。

## 七、工程细节里的审美

- 引用了未定义的 CSS 变量，整条声明会失效（例如整条 border 消失）。改变量名前全局搜一遍引用。
- 产品界面图可以用 CSS 或 SVG 直接画，比截图清晰，也能跟随深浅主题。
- 图表、数字、价格这类必须准确的内容用代码绘制，不交给图像模型。
- 页面让电脑发烫、滚动掉帧，用户会直接判定「不高级」。给粒子数、blur 层数、常驻动画数量设上限，canvas 动效在不可见时停帧。
- 首页有异步数据时先给骨架或缓存值，别让人第一眼看到一排 0。

## 八、文案（文案也是设计）

- 修改既有页面：只改失效的事实，标题、正文、口号一字不碰；改完逐条列出原文、新文和理由。
- 需要新写文案时，先和委托人确认方向。
- 不要 AI 腔：破折号、先否定再肯定的对举句、三连排比、并列否定、表演式小标题、感叹号、书面连接词堆砌。
- 金融、代币、会员类产品避开资金盘口吻：倒计时、超额倍数、先到先得、额度告急、收益承诺。
- 对用户说话，别用开发者口吻；双语站不擅自换语言。
- 每个项目维护一张对外禁词表：内部代号、模型和供应商名、服务器位置、未上线功能的「已运行」字样等，注释和 alt 文本也要查。
