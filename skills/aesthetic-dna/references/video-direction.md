# 导演方法论

适用：广告片、品牌短片、MV、口播的创意判断。
引擎的长视频制作流程已经负责：剧本骨架与分段时长、对白标记与语速、前后段连续性、角色锁定与参考图、渲染规则，以及嘻哈、K-pop、电音、摇滚、R&B、抒情、动画等 MV 风格库，美妆、奢侈品、科技、时尚、食品饮料、汽车、烈酒、电商等广告风格和结构模板。做长视频直接交给它，这里只收它之外的创意方法。

## 一、总原则

1. **先认出情绪，再生成画面。** 看一张图、一首歌、一个产品，先抓底下那团没说出口的东西。
2. **广告卖的是人生幻觉。** 每个品类先写一句「幻觉」（观众买它时真正想成为什么）和一句「别拍」（最偷懒的镜头），再动笔分镜。
3. **五层合一。** 灵魂（情绪）、工艺（品类拍法）、拍法（叙事原型）、人格（人物形象）、转场（剪辑节奏），五层指向同一个情绪才成片。
4. **场景跟产品的真实世界走，不跟人格走。** 血压计的主人公在清晨的厨房，不在凌晨的高楼办公室。
5. **主角镜头落在情绪重音上。** 产品或主角的最强一镜放在音乐或情绪的重拍，进场要「重」。
6. **结尾先留一拍安静，再出标识。** 主色从头到尾不变调。

## 二、产品灵魂：幻觉与别拍

| 品类 | 幻觉 | 别拍 |
|---|---|---|
| 香水 | 我想被记住，或被靠近 | 瓶子旋转 |
| 口红 | 我可以重新掌控自己 | 只拍试色 |
| 跑鞋 | 我不想被原来的生活追上 | 鞋面 360 度 |
| 咖啡 | 这一刻只属于我 | 拉花特写加笑脸 |
| 腕表 | 我的时间有分量 | 表盘转台 |
| 手机 | 我的生活值得被看见 | 参数字幕满屏 |
| 护肤 | 我对自己温柔 | 前后对比夸张磨皮 |
| 啤酒 | 和朋友在一起就够了 | 干杯加大笑 |
| 保险 | 我爱的人不会被意外击倒 | 恐吓式灾难画面 |
| 母婴用品 | 我能把这个小生命照顾好 | 摆拍的完美家庭 |
| 家电 | 家务退场，生活回来 | 功能按键逐个特写 |
| 健康监测 | 我还能撑住这个家 | 冷冰冰的医疗数据界面 |

## 四、十二个场景心理

每个场景是一种心理，配一个人在做的真实动作。镜头拍动作，不拍概念。

| 场景 | 心理 | 动作示例 |
|---|---|---|
| 凌晨便利店 | 临时安慰 | 站在冰柜前很久没拿 |
| 雨夜出租车 | 过渡状态 | 额头贴着车窗 |
| 酒店电梯 | 欲望与距离 | 盯着楼层数字 |
| 空荡 KTV | 青春散场 | 一个人把歌唱完 |
| 海边停车场 | 悬停的自由 | 熄火后没下车 |
| 机场洗手间 | 离开与没发生的重逢 | 对着镜子整理衣领 |
| 地下停车库 | 被压抑的危险 | 钥匙在手里停住 |
| 霓虹小巷 | 匿名的诱惑 | 回头看了一眼 |
| 旧公寓厨房 | 清晨的撑住 | 煮水时扶着台面 |
| 地铁末班车 | 一天的尽头 | 看着对面窗里的自己 |
| 凌晨的高楼办公室 | 体面下的孤独 | 关掉最后一盏灯 |
| 屏幕光照亮的卧室 | 与机器的亲密 | 打字又删掉 |

## 五、风格库之外的行业工艺签名

| 行业 | 签名 | 拍法 |
|---|---|---|
| 家电 | 科技隐入生活 | 极简室内，产品融进家居，不单独摆拍 |
| 家居家纺 | 触觉与温馨 | 自然光、慢动作、手指划过面料 |
| 母婴宠物 | 安全与陪伴 | 柔光，接受不可控的动态，等真实反应 |
| 医疗营养 | 体内释放可视化 | 微观三维动画加健康的生活场景，信息稳重可信 |
| 文旅、游戏、办公 | 沉浸与虚实交界 | 大气风光与界面或虚拟元素自然融合 |

## 七、MV：先解出人物状态

动笔前先回答：这首歌像一个人在什么状态下活着。依次写下人格、城市、时间、身体状态、颜色、关系、不该出现什么，再分 Intro、Verse、Hook（重音）、Bridge、Outro 五拍落画面。

风格库之外几种流派最容易拍土的地方：

| 流派 | 容易拍土 |
|---|---|
| 欧美流行舞曲 | 空洞炫舞、假笑、滤镜假精致 |
| 极简 | 为极简而空、没有变化的死板、冷到没有人味 |
| 合成波、赛博朋克 | 五毛故障、霓虹拉满到俗、空有滤镜没有情绪 |
| 独立迷幻 | 廉价滤镜冒充迷幻、对称用到腻、彩虹乱堆 |
| 先锋电子 | 为怪而怪、没有咬合的乱、廉价惊吓 |

孤独主题的硬规则：禁阳光公路、情侣甜笑、暖金治愈，禁把孤独拍成被拯救。
典型误读：一首单人孤独的歌，因为大调、慢速、歌词表层提到「出走」，被拍成暖金色的两人阳光公路。三处错：证据压过了情绪判断；单人的孤独被拍成两个人的甜；矫枉过正时又一刀禁掉冷色，而这首歌本来就该冷。正确做法：每次重新读出真实情绪，拿不准就先问委托人。
